What is Terraform & How Does It Work?

Infrastructure as Code (IaC) • Assignment 6 Concepts Guide

1. What is Terraform? (Infrastructure as Code)

Terraform is an open-source Infrastructure as Code (IaC) tool created by HashiCorp. Instead of manually clicking buttons in the AWS Management Console to create VPCs, subnets, and servers, you define your entire infrastructure in text files (main.tf) using HCL (HashiCorp Configuration Language).

2. The 4-Step Terraform Workflow (Assignment 6 Steps)

1. terraform init

Downloads AWS provider plugin (hashicorp/aws) and sets up the workspace.

2. terraform validate

Verifies syntax and configuration correctness without making cloud API calls.

3. terraform plan

Compares Desired State vs Real AWS State, showing exact add (+), change (~), or destroy (-) actions.

4. terraform apply

Calls AWS REST APIs to provision resources and updates the terraform.tfstate file.

3. In-Place Modification (Assignment 6 Step 15)

When updating Name = "Assignment6-VPC-modified", Terraform knows the VPC already exists via terraform.tfstate. Because CIDR wasn't altered, it updates the tag in-place (0 added, 1 changed, 0 destroyed) without tearing down any network interfaces!

4. Event-Driven IaC Scaling (CloudWatch → Webhook → Terraform API)

In modern GitOps/IaC architectures, metrics from CloudWatch breach a threshold (e.g. RequestCount > 350), triggering an EventBridge webhook to your IaC controller. The controller updates desired_capacity in the Terraform code and triggers terraform apply, scaling out the cluster automatically and cleanly!
